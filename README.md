# Beacon Stream

Beacon Stream is a server-authoritative personal game-streaming orchestrator.

Milestone 0/1 covers the control plane, fake backends, planner, profile ownership, phone-free testing, and source-boundary documentation. The Milestone 2 branch adds the real Windows SudoVDA/DisplayConfig lifecycle backend and manual no-phone display probe. Real streaming and the Android APK come later.
