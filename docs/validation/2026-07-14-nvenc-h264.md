The probe converts deterministic D3D11 BGRA input to NV12, encodes four Annex-B access units,
forces IDR plus SPS/PPS on the first and requested frames, changes bitrate in the same encoder
session, and decodes the complete stream with FFmpeg as a test-only oracle. The script requires
FFmpeg to reach `progress=end` and report exactly four output frames; `-frames:v` does not cap or
fabricate the count. The SPS timing fields represent 120 fps as
`time_scale / (2 * num_units_in_tick)`.

The refactor matrix passes all 18 native CTests and all 487 managed tests with clean managed
formatting, PowerShell parsing, diff checks, and prohibited production-route scans. Failure-path
tests prove that lock, unlock, unmap, unregister, output-destruction, encoder-destruction, and
partial-open cleanup failures cannot release resources out of NVENC order. Ambiguous native
ownership poisons the Worker encoder, retains the DLL, D3D device, and any live input texture for
process teardown, and rejects encode or reconfigure reuse. An accepted frame that cannot be
delivered forces the next delivered access unit to IDR with SPS/PPS. An independent final review
reported no remaining P1 or P2 findings.

This validation uses only D3D11, NVENC, and test-only FFmpeg tools. It does not create or change a
display, access or control Apollo, or use ADB/emulator state.
