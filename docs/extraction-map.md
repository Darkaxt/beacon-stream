Milestone 101 note: `GameStreamRtpDecoderVideoConsumer.java`, the GameStream RTP metadata conversion in `EncodedVideoStreamPlan.java`, and the `GameStreamRtpVideoConsumer.stop()` lifecycle are original Android boundary code. They connect Beacon's already-fakeable RTP sample provider to Beacon's existing `SurfaceEncodedVideoDecoder` abstraction when server-owned metadata advertises codec/container/width/height/fps. They do not copy Sunshine, Moonlight, Artemis, Apollo, or Vibepollo source, and live GameStream RTP depacketization remains a later boundary.

Milestone 102 note: the metadata gate in `GameStreamNativeStreamClient.java`, the three-argument route composer in `AndroidNativeStreamClientFactory.java`, and the Activity wiring in `BeaconActivity.java` are original Android composition code. They keep descriptors without RTP decoder metadata on the RTSP-only path and route metadata-bearing descriptors into Beacon's UDP RTP sample-provider plus decoder-consumer boundary. They do not copy Sunshine, Moonlight, Artemis, Apollo, or Vibepollo source, and dynamic port leasing plus GameStream-specific depacketization remain later work.

Milestone 103 note: `H264RtpSampleProvider.java` and the codec-based sample-provider selection in `GameStreamRtpVideoSessionClient.java` are original Java code implementing Beacon's H.264 RTP payload boundary for single NAL, STAP-A, and FU-A packets into Annex B samples. They are based on the public RFC 6184 packetization contract, do not copy Sunshine, Moonlight, Artemis, Apollo, Vibeshine, or Vibepollo source, and leave HEVC, AV1, jitter/reordering, dynamic client port leasing, and parameter-set injection for later milestones.

Milestone 104 note: `GameStreamRtpPortLease.java`, `GameStreamRtpPortLeaseFactory.java`, the RTP-lease wiring in `GameStreamRtspTransportSessionClient.java` and `GameStreamRtspHandshakeClient.java`, the lease attachment in `GameStreamRtspSessionInfo.java`, and the leased-video-socket path in `GameStreamUdpRtpPacketSourceFactory.java` are original Java code for Beacon's Android RTP port ownership boundary.
